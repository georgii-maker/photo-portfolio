# Папка для фотографий

Сюда кладите файлы сайта. Имена — латиницей, строчными, без пробелов.

## Ожидаемые имена

| Файл | Где появляется | Обязательно |
|---|---|---|
| `work-01.jpg` … `work-12.jpg` | плитки в галерее | да (свои имена можно добавить в `js/gallery-data.js`) |
| `portrait.jpg` | раздел «Обо мне» | нет |
| `hero.jpg` | фон главного экрана | нет |
| `placeholder.svg` | заглушка, если файла нет | не удалять |

## Требования

* Формат: `.jpg` (фото), `.png` или `.webp` (графика). Расширение в `gallery-data.js` должно совпадать.
* Размер: ширина 1600–2000 px, вес 250–400 КБ. Файлы прямо с камеры (5–10 МБ) грузятся очень медленно.
* Ориентация: и горизонтальные, и вертикальные — сетка галереи «мозаичная» и сама подстраивается.
* Цвет: sRGB.

## Как ускорить

Если фотографий много, добавьте два размера: маленький для плитки (`work-01-thumb.jpg`)
и большой для полноэкранного просмотра (`work-01.jpg`), и укажите их в `gallery-data.js`.
Текущая версия сайта использует один файл на кадр — этого достаточно для портфолио.
