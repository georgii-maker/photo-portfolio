# Портфолио фотографа

Статический сайт-портфолио: галерея с фильтрами и лайтбоксом, раздел с оборудованием,
«обо мне» и контакты. **Без цен** — ни прайса, ни кнопок «заказать».

Чистый HTML + CSS + JavaScript. Без сборки, без зависимостей, без npm.
Именно поэтому сайт бесплатно и надёжно живёт на **GitHub Pages**.

---

## 1. Что внутри

```
photographer-portfolio/
├── index.html            вся страница
├── css/style.css         оформление (палитра в самом верху файла)
├── js/
│   ├── gallery-data.js   ← СПИСОК ФОТОГРАФИЙ (правится здесь)
│   └── site.js           галерея, фильтры, лайтбокс, меню
├── images/
│   ├── placeholder.svg   заглушка для отсутствующих фото
│   ├── hero.jpg          (не обязательно) большой кадр на главном экране
│   ├── portrait.jpg      (не обязательно) ваше фото в разделе «Обо мне»
│   └── work-01.jpg …     фотографии галереи
├── favicon.svg           иконка вкладки
└── .nojekyll             служебный файл GitHub Pages
```

## 2. Как добавить свои фотографии

1. Скопируйте файлы в папку `images/`. Имена — латиницей, без пробелов:
   `work-01.jpg`, `work-02.jpg`, `portrait.jpg`, `hero.jpg`.
2. Откройте `js/gallery-data.js` и впишите кадры в массив:

```js
window.GALLERY = [
  { src: "images/work-01.jpg", alt: "Портрет у окна",        tag: "портрет"  },
  { src: "images/work-02.jpg", alt: "Репортаж с репетиции",  tag: "репортаж" },
  { src: "images/work-03.jpg", alt: "Предметная съёмка",     tag: "предметка"}
];
```

* `src` — путь к файлу;
* `alt` — короткое описание (важно для поисковиков и доступности);
* `tag` — категория. Из тегов **автоматически** собираются кнопки фильтра,
  так что можно писать любые: «портрет», «репортаж», «улица», «предметка», «свадьба».

Если файла ещё нет — вместо него покажется заглушка, сайт не сломается.

**Про вес файлов.** Фотографии с камеры весят по 5–10 МБ, и это главная причина
медленного сайта. Перед загрузкой сожмите их до ~250–400 КБ и ширины 1600–2000 px
(подойдёт любой конвертер или экспорт «для веба» из редактора).

## 3. Что заменить в тексте

| Что | Где |
|---|---|
| Имя (шапка, подвал, `title`) | `index.html` — ищите `Имя Фамилия` |
| Почта, Telegram, Instagram | `index.html`, раздел `id="contact"` — там стоит пометка `ЗАМЕНИТЕ` |
| Текст «Обо мне» | `index.html`, раздел `id="about"` |
| Заголовок и подзаголовок на главном экране | `index.html`, блок `class="hero"` |
| Цвета и шрифты | `css/style.css`, переменные в `:root` (например `--accent`) |

## 4. Публикация на GitHub Pages

### Вариант А — через сайт GitHub (проще всего)

1. Создайте на GitHub новый **публичный** репозиторий, например `photo-portfolio`.
   Ничего не добавляйте при создании (ни README, ни .gitignore).
2. В папке проекта выполните (замените `ЛОГИН`):

```bash
git init
git add .
git commit -m "Сайт-портфолио фотографа"
git branch -M main
git remote add origin https://github.com/ЛОГИН/photo-portfolio.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Через 1–2 минуты сайт откроется по адресу
   `https://ЛОГИН.github.io/photo-portfolio/`.

### Вариант Б — GitHub Desktop

Add local repository → выбрать папку → Publish repository (снять галочку «Keep this code private»).
GitHub Pages всё равно надо включить вручную по шагам выше.

### Вариант В — через GitHub CLI

```bash
gh auth login
gh repo create photo-portfolio --public --source=. --remote=origin --push
```

## 5. Локальный просмотр

Просто откройте `index.html` в браузере. Либо поднимите локальный сервер
(нужен, только если хотите проверить всё как на хостинге):

```bash
python -m http.server 8000
```

и зайдите на `http://localhost:8000`.

---

## 6. Свой домен (по желанию)

1. Купите домен.
2. В настройках DNS добавьте `CNAME` на `ЛОГИН.github.io`.
3. В GitHub: **Settings → Pages → Custom domain** → введите домен.
4. Создайте в корне проекта файл `CNAME` с одной строкой — вашим доменом.
